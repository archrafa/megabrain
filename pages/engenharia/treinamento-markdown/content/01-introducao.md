# Introdução ao Markdown

## O que é Markdown?

Markdown é uma linguagem de marcação leve criada por **John Gruber** em 2004, em parceria com Aaron Swartz. A ideia era simples: permitir que qualquer pessoa escreva texto formatado usando uma sintaxe fácil de ler e escrever, mesmo em texto puro (sem formatação visual nenhuma).

Um arquivo `.md` pode ser aberto em qualquer editor de texto simples e ainda assim ser perfeitamente legível — e, quando processado por um conversor, vira HTML formatado.

## Por que usar Markdown?

- **Simplicidade**: a sintaxe é mínima e intuitiva, sem tags complexas como no HTML.
- **Portabilidade**: arquivos `.md` são texto puro, funcionam em qualquer sistema operacional e editor.
- **Foco no conteúdo**: você escreve sem se preocupar com formatação visual, apenas com estrutura.
- **Amplamente suportado**: GitHub, GitLab, Notion, Slack, Discord, Jira, Confluence e praticamente todas as ferramentas modernas de documentação e desenvolvimento entendem Markdown.
- **Versionável**: por ser texto puro, funciona perfeitamente com Git — dá para ver diffs linha a linha.

## Onde o Markdown é usado no dia a dia

1. **READMEs de repositórios** (GitHub, GitLab, Bitbucket)
2. **Documentação técnica** (MkDocs, Docusaurus, GitBook)
3. **Anotações pessoais** (Obsidian, Notion, Joplin)
4. **Mensagens em ferramentas de chat** (Slack, Discord, Microsoft Teams)
5. **Pull requests e issues**
6. **Blogs e artigos técnicos** (Jekyll, Hugo, Dev.to, Medium)

## Variações (flavors)

Existem diferentes "dialetos" de Markdown. Os mais comuns são:

| Variante | Onde é usada | Diferencial |
|---|---|---|
| CommonMark | Especificação padrão da comunidade | Define regras precisas e sem ambiguidade |
| GFM (GitHub Flavored Markdown) | GitHub, GitLab | Tabelas, listas de tarefas, texto tachado |
| MultiMarkdown | Ferramentas acadêmicas | Notas de rodapé, metadados, citações |

> Este treinamento usa como base o **GFM (GitHub Flavored Markdown)**, por ser o mais comum no dia a dia de quem trabalha com desenvolvimento e documentação técnica.

## O que você vai aprender
