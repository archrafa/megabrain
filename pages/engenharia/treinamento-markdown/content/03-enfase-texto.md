# Ênfase de Texto

## Negrito

Use dois asteriscos `**` ou dois underscores `__` ao redor do texto:

```
Este texto está **em negrito**.
Este texto também está __em negrito__.
```

Resultado: Este texto está **em negrito**.

## Itálico

Use um asterisco `*` ou um underscore `_`:

```
Este texto está *em itálico*.
Este texto também está _em itálico_.
```

Resultado: Este texto está *em itálico*.

## Negrito e itálico combinados

Use três asteriscos `***` (ou combine `**` com `_`):

```
Este texto está ***em negrito e itálico***.
```

Resultado: Este texto está ***em negrito e itálico***.

## Tachado (strikethrough)

Recurso do GFM — use dois tis `~~`:

```
Este texto está ~~riscado~~.
```

Resultado: Este texto está ~~riscado~~.

## Código inline

Use crase simples `` ` `` para destacar trechos curtos de código dentro de uma frase:

```
Use o comando `git status` para ver o estado do repositório.
```

Resultado: Use o comando `git status` para ver o estado do repositório.

## Boas práticas de ênfase

- Prefira `**` para negrito e `*` para itálico — evite misturar `_` e `*` no mesmo documento para manter consistência.
- Não abuse de ênfase: se tudo está em negrito, nada se destaca de verdade.
- Use código inline sempre que citar nomes de comandos, variáveis, arquivos ou trechos de código dentro do texto corrido.

## Tabela de referência rápida

| Efeito | Sintaxe | Exemplo |
|---|---|---|
| Negrito | `**texto**` | **texto** |
| Itálico | `*texto*` | *texto* |
| Negrito + itálico | `***texto***` | ***texto*** |
| Tachado | `~~texto~~` | ~~texto~~ |
| Código inline | `` `texto` `` | `texto` |
