Álgebra linear

O idioma nativo. Significado vira geometria, e geometria vira multiplicação de matriz.

Produto escalar: a operação que mede parecença

Um embedding é um vetor. A pergunta “estas duas coisas têm a ver uma com a outra?” vira “estes dois vetores apontam para o mesmo lado?”. O produto escalar responde: soma dos produtos componente a componente. Positivo alto = mesma direção. Zero = perpendicular, sem relação. Negativo = direções opostas.

Multiplicação de matriz: milhares de produtos escalares de uma vez

Uma matriz é uma pilha de vetores. Multiplicar duas matrizes é fazer o produto escalar de cada linha da primeira com cada coluna da segunda. É isso, literalmente, e é 90% do custo computacional de um LLM.

Cada célula do resultado é o produto escalar de uma linha por uma coluna.
Na atenção isso aparece como Q · Kᵀ: a matriz de perguntas vezes a matriz de chaves transposta. O resultado é uma grade onde a célula (i, j) diz o quanto o token i se interessa pelo token j. Toda a “compreensão de contexto” começa como um produto escalar.

O que mais aparece daqui

  • Normas (‖v‖) — tamanho do vetor. Base de LayerNorm/RMSNorm e do clipping de gradiente.
  • Transposição — reorganizar para alinhar dimensões. Onipresente e chata.
  • Decomposição de posto baixo (SVD) — a ideia de que uma matriz grande pode ser aproximada por duas magrinhas. É exatamente o truque do LoRA: em vez de treinar uma matriz d×d, treina duas d×r com r pequeno.
  • Alta dimensionalidade — em 8.192 dimensões cabem muitos conceitos quase perpendiculares entre si. É por isso que um vetor consegue carregar significado sem colidir com todo o resto.

Cálculo

A álgebra linear faz a conta. O cálculo diz em que direção mexer os pesos para a conta ficar menos errada.

Derivada é inclinação

A derivada de uma função em um ponto é a inclinação da reta tangente ali. Se é positiva, subir x aumenta f. Se é negativa, subir x diminui f. Se é zero, você está num ponto plano — topo, fundo ou sela.

Num modelo, a função não tem uma variável e sim um trilhão delas. A derivada parcial em relação a cada peso, empilhada num vetor, é o gradiente. Ele aponta a direção de subida mais íngreme da perda — então o treino anda no sentido contrário.

Descida do gradiente, com a taxa de aprendizado na sua mão

O algoritmo inteiro é uma linha: peso ← peso − η · gradiente. O η (learning rate) é o tamanho do passo. Pequeno demais, você não sai do lugar. Grande demais, você salta por cima do mínimo e diverge. Teste os dois extremos abaixo.

Regra da cadeia: por que “backpropagation” não é mágica

Uma rede é uma função composta: camada sobre camada sobre camada. A regra da cadeia diz que a derivada de uma composição é o produto das derivadas de cada etapa. Backpropagation é só aplicar isso da saída para a entrada, reaproveitando os resultados intermediários em vez de recalcular tudo.

L = f₃(f₂(f₁(x)))
∂L/∂w₁ = (∂L/∂f₃) · (∂f₃/∂f₂) · (∂f₂/∂f₁) · (∂f₁/∂w₁)

Multiplicar centenas desses fatores tem uma consequência direta: se forem quase todos menores que 1, o produto tende a zero e o gradiente some antes de chegar nas primeiras camadas. Se forem maiores que 1, ele explode. Conexões residuais e normalização existem principalmente para manter esse produto bem-comportado.

Probabilidade

O modelo não escolhe uma palavra. Ele devolve uma distribuição sobre todas elas, e alguém amostra.

Softmax e temperatura

A última camada cospe um score bruto (logit) para cada token do vocabulário. Softmax exponencia e normaliza, virando probabilidades que somam 1. A temperatura divide os logits antes disso: baixa realça as diferenças, alta as achata.

Temperatura 0,05 deixa o modelo praticamente determinístico — sempre o token de maior logit. Temperatura 2,0 dá chance real a candidatos improváveis. top_p corta a cauda: mantém só os tokens mais prováveis até acumular p, e redistribui o resto. As barras apagadas foram eliminadas antes da amostragem.

Cross-entropy: a perda que o treino minimiza

Durante o treino existe uma resposta certa: o token que realmente vinha a seguir no texto. A perda é −log(p), a probabilidade que o modelo deu para o token correto. Se deu 0,9, a perda é 0,105. Se deu 0,01, a perda é 4,6. O logaritmo pune confiança errada de forma brutal — e essa punição é exatamente o sinal que se propaga de volta pela rede.

Perplexidade é a perda exponenciada, e tem uma leitura intuitiva: “entre quantas opções equiprováveis o modelo está efetivamente hesitando”. Perplexidade 1 = certeza absoluta. Perplexidade 50.000 = chute uniforme no vocabulário inteiro.

O resto do kit

  • Máxima verossimilhança — o objetivo formal do pré-treino: ajustar os pesos para maximizar a probabilidade dos textos observados.
  • Divergência KL — distância entre duas distribuições. Aparece na perda, e explicitamente no RLHF para impedir que o modelo ajustado se afaste demais do original.
  • Entropia — incerteza média de uma distribuição, em bits. É o instrumento no painel acima.
  • Amostragem — greedy, top-k, top-p, beam search. Todos operam sobre a mesma distribuição, só diferem em como sorteiam.

A volta completa

Um token entrando e a matemática toda em sequência.

1. token → id → linha da matriz de embedding  // álgebra linear 2. Q·Kᵀ → softmax → ·V, repetido por camada  // álgebra linear + probabilidade 3. MLP: expande, não-linearidade, contrai  // álgebra linear 4. projeção final → logits sobre o vocabulário  // álgebra linear 5. softmax(logits / T) → amostragem  // probabilidade ── só no treino ── 6. perda = −log(p do token correto)  // teoria da informação 7. gradiente por regra da cadeia, saída → entrada  // cálculo 8. peso ← peso − η · gradiente  // otimização

Na inferência só rodam os passos 1 a 5. Os passos 6 a 8 rodaram milhões de vezes, meses atrás, num cluster, e o resultado congelado é o arquivo de pesos que você carrega.

Ordem sugerida de estudo

  • Álgebra linear primeiro. Sem ela, nada mais faz sentido. Foque em produto escalar, multiplicação de matriz e o que significa uma transformação linear. O Essence of Linear Algebra do 3Blue1Brown resolve a intuição em poucas horas.
  • Cálculo em seguida, e só a parte que interessa: derivadas parciais, gradiente e regra da cadeia. Integrais quase não aparecem em LLM.
  • Probabilidade em paralelo com o cálculo — softmax, verossimilhança, entropia. É a ponte entre a matemática e o comportamento que você observa em produção.
  • Otimização por último, e tranquilamente como caixa-preta. Saber que AdamW usa momento e taxas adaptativas por parâmetro já cobre a conversa por um bom tempo.
